# Mi Pokédex

Para ir completando la Pokédex. Anda offline en el celu y en la compu.

**Link:** https://matinaipapa.github.io/pokedex/

- **iPhone:** abrir el link en Safari → Compartir → "Agregar a pantalla de inicio". Usarla siempre desde el ícono.
- **Android:** abrir el link en Chrome → menú ⋮ → "Agregar a pantalla principal" (o abrir el archivo `index.html` con Chrome).
- **PC:** abrir el link o el archivo `index.html` con cualquier navegador.

Para pasar el progreso de un dispositivo a otro: **💾 Guardar progreso** en uno y **📂 Cargar progreso** en el otro.
